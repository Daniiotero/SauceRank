# [Nombre del proyecto]

- El proyecto SauceRank se basa en valorar la discografía del artista Eladio Carrión de manera fácil y finalmente mostrar los temas favoritos de la comunidad. Va dirigida para todos los fans del artista

## Stack

- Lenguaje: Java
- Framework / runtime: Spring Boot 3 + Java 21 y React
- Base de datos: PostgreSQL
- Tests: JUnit(backend) y Vitest(frontend)

## Comandos

- `[comando dev]` — arranca el servidor en local
- `[comando test]` — ejecuta los tests (deben pasar antes de cada
  commit)
- `[comando lint]` — revisa el estilo (antes de cada PR)
- `[comando build]` — compila para producción
